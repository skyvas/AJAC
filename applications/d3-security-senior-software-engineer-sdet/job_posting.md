## Overview
D3 Security is a leading provider of Next-Gen SOAR (Security Orchestration, Automation, and Response) and AI-driven autonomous SOC solutions (platform "Morpheus"). The company is hiring a Senior Software Engineer / SDET to lead testing lifecycle activities, design automated test environments, and validate core security SaaS features.

## Key Responsibilities
- Participate in all aspects of manual and automated testing, including functional analysis, test planning, test case creation, environment setup, and regression testing.
- Design, deploy, and maintain test environments for functional, performance, and security testing.
- Work closely with the DevOps and deployment teams on CI/CD pipelines (Jenkins, Git branching/merging) and production releases.
- Analyze and troubleshoot issues during the testing lifecycle, producing comprehensive internal documentation, release notes, and defect reports.
- Guide and mentor QA team members on test automation best practices.

## Requirements
- Bachelor’s degree in Computer Science, Engineering, or equivalent.
- 5+ years of experience in software quality assurance with strong hands-on test automation and scripting.
- Experience with CI/CD tools (Jenkins, GitHub) and test execution pipelines.
- Proficiency in scripting and programming (Python, SQL, Shell, C#).
- Solid understanding of databases (PostgreSQL, MS SQL Server, MongoDB) and backend API validation.
- Strong analytical and debugging skills in cybersecurity or enterprise software environments.
