## Overview
Autodesk is seeking a Senior SDET Engineer to join the Autodesk Construction Cloud (ACC) product team in Vancouver. The role focuses on creating and maintaining robust QA test services and tools, system monitoring, and integrating automated tests into continuous delivery pipelines for ACC's enterprise software suite.

## Key Responsibilities
- Architect, implement, and maintain QA test automation services and frameworks for ACC products (Project, Field, and BIM Manager tools).
- Oversee system reliability and monitoring, including analyzing API traffic, performance metrics, and failure rates.
- Integrate automated UI, API, and regression tests into CI/CD pipelines to ensure seamless releases.
- Collaborate with global cross-functional development, product, and operations teams.
- Provide technical mentorship to junior engineers and champion quality engineering best practices.

## Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or equivalent.
- 5+ years of experience in test automation, framework architecture, and software development in test.
- Deep expertise in API testing (REST / GraphQL) and UI automation (Playwright / Selenium / TypeScript / Java / Python).
- Hands-on experience with CI/CD systems, cloud platforms (AWS), and containerization (Docker, Kubernetes).
- Strong communication, analytical thinking, and mentorship capabilities.
