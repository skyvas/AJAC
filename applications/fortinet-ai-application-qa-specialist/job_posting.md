# Job Posting: AI Application QA Specialist

- **Company**: Fortinet
- **Title**: AI Application QA Specialist
- **Location**: Burnaby, BC (Greater Vancouver Area)
- **Source URL**: https://www.fortinet.com/corporate/careers
- **Date Collected**: 2026-08-19
- **Remote Policy**: On-site / Hybrid (Burnaby office)
- **Seniority**: Mid-to-Senior Specialist / Release QA Team

## Overview
Fortinet is seeking an AI Application QA Specialist to join the FortiOS Release QA team in Burnaby, BC. This role focuses on testing and validating AI-powered applications that support FortiOS verification and automated quality engineering.

## Key Responsibilities
- Design and execute comprehensive test plans for AI features, covering functional, regression, and edge-case testing across AI models and application logic.
- Perform data verification on training, validation, and production datasets to ensure quality, integrity, and accurate labeling.
- Set up automated tests, monitor test runs, investigate failures, and maintain automated test scripts.
- Identify, document, and track software defects throughout the testing lifecycle in close collaboration with R&D and release engineering.
- Review new AI feature requirements and design test architectures to continuously improve FortiOS quality validation.

## Requirements
- Bachelor's or Master's degree in Computer Science, Data Science, Engineering, or related technical field.
- Experience in automated software testing and quality engineering.
- Familiarity with AI-assisted testing workflows, LLMs, prompt engineering, and evaluation pipelines.
- Proficiency in programming and scripting (Python, Shell/Bash).
- Knowledge of networking fundamentals (TCP/IP, routing, DNS, DHCP, VPNs, firewalls).
- Strong analytical and problem-solving skills with defect tracking experience.
