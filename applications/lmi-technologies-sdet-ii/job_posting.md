## Overview
LMI Technologies, a global leader in 3D scanning, sensor technologies, and machine vision solutions, is seeking a Software Development Engineer in Test (SDET) II to join the Software Operations team in Burnaby, BC. This role serves as an Automation and Build Developer to engineer automated test solutions, support core build pipelines, and ensure software quality across 3D inspection and machine vision products.

## Key Responsibilities
- Design, build, and maintain automated test frameworks and test suites for software and sensor applications.
- Engineer automation security and validation solutions within the CI/CD build pipeline.
- Optimize and support core automated build pipelines and execution infrastructure.
- Collaborate with software development teams to ensure software changes are thoroughly testable and meet quality benchmarks.
- Investigate, reproduce, and document defects with clear actionable diagnostic logs.

## Requirements
- Bachelor’s degree in Computer Science, Software Engineering, Electrical Engineering, or related discipline.
- 3+ years of experience in test automation, build engineering, or SDET roles.
- Strong programming and scripting skills (Python, TypeScript, C++, or Shell/Bash).
- Experience with CI/CD build pipelines (Jenkins, GitHub Actions, GitLab CI).
- Strong debugging, analytical thinking, and cross-functional communication skills.
